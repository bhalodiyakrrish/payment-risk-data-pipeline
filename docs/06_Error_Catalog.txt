# Data Quality Error Catalog

## 1. Purpose

This document defines the standardized error codes produced by the validation layer.

Error codes provide a consistent machine-readable representation of data-quality failures.

---

## 2. Customer Errors

| Error Code | Description |
|---|---|
| CUST_MISSING_ID | Customer ID is missing |
| CUST_DUPLICATE_ID | Customer ID is not unique |
| CUST_MISSING_NAME | Customer name is missing |
| CUST_MISSING_EMAIL | Customer email is missing |
| CUST_INVALID_EMAIL | Customer email format is invalid |
| CUST_INVALID_COUNTRY | Customer country is unsupported |
| CUST_INVALID_STATUS | Customer status is unsupported |
| CUST_INVALID_DATE | Registration date is invalid |

---

## 3. Merchant Errors

| Error Code | Description |

---

## 5. Severity

### Critical

The record cannot safely enter the trusted data layer.

Examples:

- Missing transaction ID
- Duplicate transaction ID
- Invalid amount
- Missing customer ID
- Missing merchant ID
- Unknown customer
- Unknown merchant

### High

The record violates an important business or domain constraint.

Examples:

- Invalid currency
- Invalid payment method
- Invalid transaction status
- Invalid gateway

### Medium

The record contains a quality issue that is less critical to the transaction processing logic.

Examples:

- Invalid customer email
