## 5. Transaction Validation

Transaction validation is performed against the raw transaction dataset before trusted data is introduced into the Silver layer.

The transaction validation process checks:

- Transaction ID completeness
- Transaction ID uniqueness
- Customer ID completeness
- Merchant ID completeness
- Customer referential integrity
- Merchant referential integrity
- Transaction timestamp validity
- Transaction amount validity
- Currency validity
- Payment method validity
- Transaction status validity
- Country validity
- Gateway validity
- Response code validity
- Device type validity

### Reference Data

Customer and merchant IDs are loaded from their respective source master datasets.

A transaction is considered to have valid referential integrity only when:

```text
transaction.customer_id exists in customer master
transaction.merchant_id exists in merchant master
